About SYNAPSE

It began as an Honours research project

SYNAPSE started as my Honours research project at Edinburgh Napier University.

I wanted to explore a simple question: could an AI tutor help people learn secure software development without taking the thinking away from them?

That became a working platform for learning Java, Python for cybersecurity and secure software development.

Today, SYNAPSE combines guided tutoring, coding exercises, security practice and tools that let learners see what their code is doing while it runs.

How it works

The tutor does not begin by giving the answer

It first asks what you think is happening, then works from your response. If you need help, it can give a small hint, help with the approach, or use another example to explain the idea.

SYNAPSE uses Claude, GPT-4o and Gemini for different parts of the tutoring workflow.

They are connected through the Model Context Protocol, which allows the platform to use different models and teaching tools through a common interface.

The aim is practical: use each model where it is useful without making the learning experience depend on a single provider.

Learning by doing

Detect, understand, remediate

SYNAPSE includes Java and Python for cybersecurity, together with secure software development exercises.

The security work follows the same basic process used throughout the research:

1

Detect

First, find the problem.

2

Understand

Then understand what it actually does.

3

Remediate

Finally, repair it and see what changes.

ShopSecure was created for this purpose. It is a deliberately vulnerable web application used to practise identifying and repairing security weaknesses across six OWASP Top 10 (2021) categories.

Seeing code run

The steps between the code and the result

One part of SYNAPSE that is continuing to grow is the program execution work.

Instead of only showing code and its final output, the lesson can show the state of the program as it changes.

A learner can see a variable change value, a loop move to its next iteration, a comparison become true or false, or a function return to the place that called it.

Nothing there is a recording. Each lesson runs the algorithm and records what actually happens, step by step, which is why you can move backwards through it.

The purpose is to make the steps between the code and the result easier to follow.

Accessibility

Removing barriers rather than adding exceptions

Accessibility was part of the project from the beginning.

The platform includes 18 features that can change how a lesson looks or feels to use, including font and spacing controls, contrast options, focus tools, reduced motion and reading support.

The original research was designed with particular attention to learners with ADHD, dyslexia and executive function differences.

It was then tested with both neurodivergent and neurotypical participants.

In the feasibility pilot, both groups reported comparable cognitive load.

The idea was not to create a separate experience for one group of learners. It was to remove barriers that can make technical learning unnecessarily difficult.

Research

SYNAPSE is also a research project

The paper:

SYNAPSE: A Multi-LLM Orchestrated AI Tutor for Secure Software Development Education with Neurodivergent-First Design

was accepted at IEEE ICSME 2026 in the Tool Demonstration and Data Showcase track.

In a feasibility pilot with 19 learners, SYNAPSE achieved a System Usability Scale score of 76.4 and an engagement score of 4.2 out of 5.

Confidence in identifying and fixing web vulnerabilities increased by 1.1 points on average and by 1.6 points among beginners.

These are early results from a small feasibility study, rather than evidence of population-level effectiveness.

Who SYNAPSE is for

People learning programming, cybersecurity or secure software development

That might be someone writing their first Java program, someone moving into cybersecurity, or someone who already knows how to code but wants more practice understanding security problems.

It can also be used in teaching and training settings.

The platform is still growing, and feedback from the people using it helps decide which lessons, explanations and tools are developed next.
