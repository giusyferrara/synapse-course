SYNAPSE also shows the execution behind it. You can follow the state of the program as it changes, see which values moved, which stayed the same and why the program reached the current line.

Step forwards, step backwards, rewind to the start, or drag through the whole run. The active line is highlighted, the current variables are listed, and each step says what changed and what did not. How SYNAPSE teaches

It asks before it answers

The tutor starts by finding out what the learner thinks is happening, then works from that answer instead of immediately giving the solution.

Hints in stages

First, a small nudge. Then, help with the approach. If more help is needed, the tutor can show a related example. The learner still has to work through the original problem.

When someone gets stuck

After 40 seconds without progress the tutor offers a gentle prompt, after 90 seconds a different way in, and after 180 seconds a smaller step to start from.

Different explanations

An explanation does not work for everyone in the same way. SYNAPSE can try another route, such as a smaller example, an analogy or a visual execution of the code.

Program logic visualisation

See the state, not only the code

A program changes one small thing at a time.

SYNAPSE records those states so a learner can move through them, compare one step with the next and see exactly what changed.

That can mean a variable changing from 4 to 9, a pointer moving to the next item, a new dictionary entry appearing, a function call being created or a recursive call returning.

The aim is to make the reasoning visible.

How it is built

Model Context Protocol

Built on an open interface

SYNAPSE uses the Model Context Protocol to connect the tutor with teaching tools through a shared interface. This makes it easier to change or add compatible models and tools without rebuilding the whole tutoring system around one provider.
