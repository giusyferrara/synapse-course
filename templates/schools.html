Using SYNAPSE with a group

If you teach, we would like to hear from you

SYNAPSE is used by individual learners, and it is also being developed for structured teaching and training.

If you teach programming, cybersecurity or secure software development and would like to try the platform with a group, please get in touch.

The platform is free to use while it is being tested with learners, so trying it with a class costs nothing at the moment.

Feedback from educators is one of the things that decides what gets built next. If something is missing for the way you teach, that is worth telling us.
